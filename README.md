# М-ТРЕНИНГ — новый логотип 2026: линия «КОД М»

**Футбольная школа силового тренинга для детей и подростков.**
Новая линия от старого знака: мяч из осколков собран в ровную сферу, разлёт
и кораблик убраны, а зазоры между шестью панелями читаются как буква М —
разрешённая монограмма школы. Орбитальные дуги Gold/Lite дают траекторию
движения. Палитра: Royal `#1B44D8`, Navy `#0A1633`, Gold `#F2C230`,
Lite `#6E8CFF`. Эмблема — V «ОРБИТА» (гранёный мяч в кольце shards),
монограмма-пьедестал W «ОПОРА» — альтернатива. Леттеринг — varsity.
